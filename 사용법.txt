============================================================
      [산나비 커스텀 컨트롤러] Pro Micro 완성 가이드 & 사용 설명서
============================================================

이 폴더를 압축해서 기기를 가지고 있는 팀원에게 그대로 전달해 주시면 됩니다.
전달받은 팀원은 아래 순서대로 진행하면 5분 안에 세팅하고 테스트할 수 있습니다.

────────────────────────────────────────────────────────────
1. 하드웨어 배선 확인 (핀 연결)
────────────────────────────────────────────────────────────
* 아두이노 내부 풀업(INPUT_PULLUP)을 사용하므로 저항이 필요 없습니다.
* 모든 버튼의 한쪽 다리는 해당 디지털 핀에, 반대쪽 다리는 모두 [GND]에 연결합니다.

  [조이스틱]
  - VCC  ──> 5V (또는 VCC)
  - GND  ──> GND
  - VRx  ──> A0
  - VRy  ──> A1
  - SW   ──> 디지털 2번 핀

  [버튼 4개]
  - East 버튼  (점프 / Space)        ──> 디지털 7번 핀 & GND
  - North 버튼 (사슬팔 / Mouse Left) ──> 디지털 6번 핀 & GND
  - South 버튼 (대시 / Shift)        ──> 디지털 8번 핀 & GND
  - West 버튼  (상호작용 / F)        ──> 디지털 5번 핀 & GND

────────────────────────────────────────────────────────────
2. 아두이노 코드 업로드 (Arduino IDE)
────────────────────────────────────────────────────────────
① 'promicro.ino' 파일을 아두이노 IDE로 엽니다.
② 상단 메뉴 [툴] -> [보드] -> [Arduino AVR Boards] -> [Arduino Leonardo] 를 선택합니다.
   ※ Pro Micro는 Leonardo와 동일한 ATmega32U4 칩셋이므로 Leonardo로 지정하면 100% 호환됩니다.
③ [툴] -> [포트] 에서 인식된 COM 포트를 선택합니다.
④ [업로드(→)] 버튼을 누릅니다.

※ 트러블슈팅 (업로드 에러 시):
   - Pro Micro 보드는 업로드 시 포트가 잠깐 바뀌는 경우가 있습니다.
   - 만약 업로드가 안 되면 보드의 RST 핀과 GND 핀을 전선으로 빠르게 '두 번' 쇼트시키면
     8초 동안 강제 부트로더 모드가 켜지며 정상 업로드됩니다.

────────────────────────────────────────────────────────────
3. PC 프로그램 준비 (처음 1회만 실행)
────────────────────────────────────────────────────────────
① 친구 PC에 Python(파이썬 3)이 설치되어 있어야 합니다.
   (파이썬 설치 시 'Add python.exe to PATH' 체크 필수)
② CMD(명령 프롬프트)를 열고 필수 라이브러리를 설치합니다:
   pip install pyserial pydirectinput

────────────────────────────────────────────────────────────
4. 실행 및 단계별 테스트 (추천 순서)
────────────────────────────────────────────────────────────
① Pro Micro를 PC에 USB로 연결합니다.
② 'run.bat' 파일을 더블 클릭하여 실행합니다. (또는 cmd에서 python controller.py)
   -> 자동으로 연결된 COM 포트를 감지하여 연결됩니다.

③ [1단계: 하드웨어 배선 테스트]
   SANABI> test
   - 키보드를 누르지 않고, 화면에 센서와 버튼이 정상적으로 읽히는지 확인합니다.
   - 버튼을 누를 때마다 화면의 누른 키 목록에 불이 들어옵니다.
   - 테스트가 끝나면 [Ctrl + C]를 눌러 메뉴로 복귀합니다.

④ [2단계: 조이스틱 중심점 보정]
   SANABI> calibrate
   - 조이스틱을 가만히 둔 상태에서 입력하면 현재 위치를 중앙(Center)으로 자동 보정합니다.

⑤ [3단계: 산나비 게임 플레이 시작]
   SANABI> start
   - 실제 DirectInput 키/마우스 송출이 시작됩니다.
   - 산나비를 켜고 게임을 플레이하시면 됩니다!
   - 종료하려면 [Ctrl + C]를 누릅니다.

────────────────────────────────────────────────────────────
5. 유용한 명령어 목록
────────────────────────────────────────────────────────────
* bind <버튼> <키>      : 버튼에 원하는 키 지정 (예: bind north mouse_left)
* unbind <버튼>         : 해당 버튼 매핑 해제
* set threshold <숫자>  : 조이스틱 감도 조절 (기본: 120, 숫자가 작을수록 민감함)
* set port <포트명>     : COM 포트 수동 변경 (예: set port COM4)
* status                : 현재 매핑 상태를 표로 한눈에 확인
* keys                  : 등록 가능한 특수키/마우스 키 목록 확인
* save <이름>           : 현재 세팅 저장 (예: save sanabi)
* load <이름>           : 세팅 불러오기 (예: load sanabi)
* exit                  : 프로그램 종료
